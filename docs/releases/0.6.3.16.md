# 0.6.3.16 更新说明

对齐上游 20 个提交，主线是接入 Na 云端助手，并补齐 ACP 共享会话、首次启动安装进度与中文化。

## 更新弹窗精简版

- 新增 Na 云端助手：连接、流式会话、历史同步、通知与例行任务，执行与模型配置在云端完成。
- ACP 会话生命周期改为本地/远端共享实现，远端会话的中断与恢复路径统一。
- 首次启动：终端环境安装显示进度与通知，缺少环境时给出可重试提示。
- 新建对话不再被终端安装状态阻塞。
- 完善 Agent 名称、权限提示、任务执行状态与终端设置的英文文案。

## 完整说明

### Na 云端助手

- 新增云端运行时，覆盖连接与准入、流式会话、历史同步、个人资源、通知投递、例行任务与 Composio 集成。
- 附件与环境信息上报接入；设置页与 Agent 目录新增 Na 入口。
- 依赖补齐：账号仓储的会话代际与云端令牌访问、通知图标资源、ACP 档案的 Na 归属绑定。

### ACP 与聊天

- ACP 会话生命周期共享化，本地与远端会话走同一套观察与恢复路径。
- 表格流式输出结束后继续渲染剩余文字（此前会截断）。
- 抽屉会话行距调整。

### 首次启动

- 系统安装进度与通知，安装前台服务随之申报。
- 启动环境提示改为可操作提示，不再静默失败。
- 新建对话解除对终端安装完成的依赖。

### 保留的本仓能力

- 宠物浮层、工具活动条、会话运行时 LRU 回收、IM 渠道服务声明、分发渠道版本号策略。
- 多步首次启动向导与环境预设（上游已删四步页，本仓保留）。

## 兼容性

- 旧版本写入的模型缓存缺少后加字段（displayName / inputModalities / outputModalities /
  supportedReasoningLevels）时，读取前会补齐默认值，避免升级后模型清单读取失败。

## 验证

全部改动只过编译门（`verify-omniinfer` 全绿），未做真机回归。建议优先验证三条路径：
Na 页连接、通知权限授予、首次启动安装进度。
